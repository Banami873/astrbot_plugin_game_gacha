# 明日方舟 / 星穹铁道抽卡模拟器

在群里模拟《明日方舟》的抽卡：卡池、概率、水位、保底、选调、联动保底、300 井与寻访数据
契约都照游戏内，结果画成游戏内的寻访结果图。**本期只做方舟**，星穹铁道留位不实现。

[仓库](https://github.com/Banami873/astrbot_plugin_game_gacha)

## 安装

1. 把整个插件目录放到 AstrBot 的 `data/plugins/astrbot_plugin_game_gacha/`；
2. 在 AstrBot 面板「插件」里启用它（配置项会自动出现，见下）；
3. 重启 AstrBot。日志里出现下面两行说明数据装载成功：

   ```
   已装载 NNN 个卡池，快照时间 …，名单 N 条，限定干员 NN 名
   已装载 NNN 名可抽取干员
   ```

4. 群里发 `/抽卡帮助`，照着用。

存档与缓存都在 `data/plugin_data/astrbot_plugin_game_gacha/`：`gacha.db` 是抽数、水位与
仓库，`cache/` 是立绘与结果图。删掉 `cache/` 只会让立绘重新下载，不会丢抽数。

## 指令

| 指令 | 说明 |
|---|---|
| `/抽卡帮助` | 一屏说明 |
| `/抽卡签到` | 每天领一次抽数（默认 +10，重复签到不加） |
| `/单抽 [类别] [池名前缀]` | 抽 1 次 |
| `/十连 [类别] [池名前缀]` | 抽 10 次 |
| `/卡池查询 [类别\|全部]` | 正在开的池子、UP 名单与结束时间 |
| `/契约兑换 <75\|200\|300> [干员名]` | 用寻访数据契约换干员 |
| `/自选 [类别] [池名] [序号或名字...]` | 中坚甄选 / 定向甄选：从官方范围里选本期 UP |
| `/潜能仓库 [页码]` | 已获得的干员与潜能 |
| `/抽数修改 <整数> [@成员]` | 管理员增减抽数，可写负数 |

类别只认五个词：**限定 / 常驻 / 限时 / 中坚 / 联动**；想精确到某个池就在类别后面写池名
前几个字，例如 `/十连 限定 庆典`。名字有歧义时会把候选列出来让你重打，不会替你挑。

9 条指令已全部可用——SPEC 原定 7 条，契约兑换是补上的第 8 条（否则限定池的契约只能攒不能花），
自选是补上的第 9 条（中坚甄选与定向甄选没有固定 UP，得玩家自己选）。

`/自选` 是两段式：不带参数先列候选（6★ 在前、5★ 在后，**连续编号 1…n**），把要选的人发出来
（序号、名字、二者混用都行）→ 只给预览、不落库 → 回「确认」才写入，**提交即锁定、不可变更**。
进了「待选」之后不用再带指令，直接发 `2 9 13 14 15` 就会被截获（5 分钟内、仅发起人）。

## 规则实现到哪一步

抽卡行为按官方公告逐条对齐，下面这些都已生效：

- **概率与水位**：3★ 40% / 4★ 50% / 5★ 8% / 6★ 2%，第 50 抽起每抽 +2%、第 99 抽必出；
  水位按池类分组，标准与限时共用一组、中坚单独一组，限定与联动每池一组、池结束清零；
  每个池的前 10 抽内必出一个 5★（只保本池第一次）。
- **星级内选人**：UP 名单与份额按池型取（常驻两名各 25%、限定共 70%、联合行动与卫戍只出
  名单内的人）；限定池的 6★ 只含当期 UP + 同系列已解限的往期限定 + 标准干员，其中同系列
  最近三名限定在剩余 30% 里享 5 倍权重。
- **选调**：常驻/中坚累计 150/300 抽后，下一次 6★ 依次必为 UP 之一、另一名；限时单 UP 池
  连续 150 抽没出当期 UP 时，下一次 6★ 必为它（中途抽到会清零重算，不算用掉）。
- **联动保底**：2026-05-01 之前的池「前 120 抽必得、只一次」，之后的池「每 120 抽必得、
  中途抽到清零」，且新池另有「前 50 抽没出 UP 5★ 时下一个 5★ 必为它」。
- **限定池**：每抽积 1 份寻访数据契约；本池累计跨过 300 抽时额外赠送当期限定（每期一次，
  不占抽数、不产契约）；池结束时剩余契约作废。
- **契约兑换**：`/契约兑换 75` 换当期 5★ UP；`200 <名字>` 换本系列到年限的往期限定 6★；
  `300 <名字>` 换本期 6★（当期 UP + 同系列已解限但未降价的往期）。200 档的降价日是一张
  显式表（`resources/limits.json`，由 `tools/build_limits.py` 生成：4/5 年估算 + 官方公告
  能确认的观测点修正），估算项在界面标「按估算日期」。兑换不推进水位、不产生新契约。
- **自选池**：中坚甄选从 12 名 6★ 里选 2 名（各占 6★ 的 25%，其余 10 名各 5%）、24 名 5★ 里
  选 3 名（合计约 50%）；定向甄选从 6 名 6★ 里选 3 名（合计 100%，其余 6★ 不出）、6 名 5★ 里
  选 3 名（合计 60%）。可出范围与名额取自官方 `dynMeta`，**范围外的人一次都抽不到**；
  未自选时抽卡会被拒且不扣抽数，自选一次锁定、本期不可变更。
- **潜能仓库**：`/潜能仓库` 按星级从高到低列已获干员，潜能 = 重复获得次数（上限 5），
  一页 12 名，页码越界回第 1 页。

任何一个池的 UP 名单缺失时会降级成「同星级均分」，结果里会写明，不会静默算错。
池名抓不到时也一样：显示官方固定叫法（`DOUBLE` 一律叫「常驻标准寻访」），
不会把 `DOUBLE_79_0_5` 这类内部 id 念给玩家；中坚甄选按游戏里的全称显示成「中坚甄选15」。

## 数据从哪来

**双源**，缺一不可：

| 来源 | 提供什么 | 为什么不能只用它 |
|---|---|---|
| 官方表 `gacha_table.json` / `character_table.json` | 池 id、池型、起止时刻、概率与保底参数、井与契约参数、限定干员名单、干员星级 | 近期池名是占位串「适合多种场合的强力干员」，`LIMITED` 没有 UP 名单 |
| PRTS Wiki 的「卡池一览」与「干员一览」 | 真实池名、每池 UP 名单、干员能出现在哪类寻访里 | 没有概率与机械参数 |

快照随包放在 `resources/snapshot/`，重建命令（在 AstrBot 根目录执行）：

```bash
.venv/Scripts/python.exe data/plugins/astrbot_plugin_game_gacha/tools/build_data.py
# 只回读现有快照、重新规范化，不联网：
.venv/Scripts/python.exe data/plugins/astrbot_plugin_game_gacha/tools/build_data.py --offline
# 骨架更新后必须重算「往期限定什么时候降到 200 档」（否则新限定池进不了兑换名单）：
.venv/Scripts/python.exe data/plugins/astrbot_plugin_game_gacha/tools/build_limits.py
```

`build_limits.py` 只读快照、不联网；`--check` 只比对不写盘。忘了重跑也不会静默出错——
`tests/test_exchange.py` 里有一条用例会直接报红。

PRTS 有 WAF，抓取带完整浏览器头并按 1 秒/次限速。解析只依赖标准库 `html.parser`，不装
`beautifulsoup4`——多一个运行时依赖就多一种「装完起不来」。

## 配置项

面板里都能改，默认值与 `SPEC.md` 一致：

| 键 | 默认 | 说明 |
|---|---|---|
| `enable_image` | 开 | 关掉后一律文字，且不装载素材、立绘与字体 |
| `image_quality` | 中 | 单抽精一立绘的缓存尺寸：高 1024px / 中 800px / 低 640px |
| `signin_reward` | 10 | 每日签到抽数 |
| `newbie_bonus` | 30 | 新人一次性抽数 |
| `data_refresh_hours` | 6 | 官方表检查间隔（保留给后续定时刷新，暂不生效） |
| `prts_refresh_hours` | 24 | PRTS 抓取间隔（同上） |
| `allow_network` | 开 | 关掉后只用快照，且不下载立绘 |

## 出问题时会怎样（降级行为）

| 情况 | 表现 |
|---|---|
| 卡池快照缺失 / 解析失败 | 插件照常加载，抽卡与查询提示「卡池数据未就绪：<原因>」并给重建命令 |
| 干员数据缺失 | 同上，提示干员表的问题；`/卡池查询` 仍可用 |
| 出图失败（缺字体、缺素材、内存不足） | 记一条警告日志，**降级为文字结果**；抽数与水位已经入账，不回滚 |
| 立绘下载失败 | 画一块占位，不影响抽卡结果；下次用到会再试 |
| 自选池缺范围数据（`dynMeta` 无 `rarityPickCharDict`） | 退回「同星级均分」且不要求自选，结果里标「自选范围未获取」。现有 15 个中坚甄选与 8 个定向甄选全都带该字段，这是防御分支 |
| 配置项写坏（类型不对） | 该项回退到默认值，其余照常 |

## 自检

换机器、换了数据文件之后，跑一条命令自证装对了：

```bash
.venv/Scripts/python.exe data/plugins/astrbot_plugin_game_gacha/tools/selfcheck.py
```

正常输出（数字随版本增长）：

```
commands=9 tables=8 snapshot=ok
  指令：十连、单抽、卡池查询、契约兑换、抽卡帮助、抽卡签到、抽数修改、潜能仓库、自选
  表：inventory、limited_state、meta、pity、pool_choice、pool_select、pool_state、users
  快照：卡池 461 个 / 干员 318 名 / 名单 71 条
```

退出码非 0 时，下面会逐条打印缺什么：指令「帮助里写了但没注册」、表「声明了但库里没有」、
快照「哪份解析不了」。

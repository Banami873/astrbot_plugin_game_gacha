## Background

issue 05 做完 UP 份额后，限定池 6★ 的候选仍是「27 名限定 + 标准」，于是 2021 年春节的
「年」会从 2026 年庆典池里冒出来——概率表看起来完全正常，只是抽出了游戏里不可能出现的人。
R-11 里「同类系列最近三名限定 ×5」也一直没接。用户 2026-11-15 决定**跳过 06-10，先把
R-11 做完**，本 issue 就是从原 issue 07 拆出来的那一块。

PRTS「寻访规则」原文比旧版 SPEC 记的更细，三条一起才成立：

1. 限定寻访的 6★ 池 = **当期 UP + 同系列往期限定 + 标准寻访干员**。系列只有三档：
   春节（1–2 月）、庆典（5 月与 11 月）、夏季（8 月）。
2. 同系列按实装时间倒序的**最近三名**限定，在「获得的 6★ 不是当期 UP」的场合权重 ×5。
3. 限定干员在当期池结束后有**最多 11 个月解限期**，期限内不进任何限定寻访。

第 3 条决定「最近三名」到底是谁。2026-05【承诺】里最近登场的是凛御银灰（2025-11），
但官方公告的 5 倍名单是「新约能天使 / 荒芜拉普兰德 / 维什戴尔」——凛御银灰才登场
6 个月，**根本不在池子里**，自然谈不上加权。

## Goal

限定池的 6★ 只从「同系列 + 已解限 + 当期 UP」的限定与标准寻访干员里出；剩余 30% 中，
同系列已解限的最近三名权重为其他人的 5 倍。`/卡池查询` 让玩家看得见这三个人。

## Scope

- `games/arknights/limited.py`：从卡池快照派生系列、登场时间、解限期、可登场集合与
  5 倍名单。每个 `LIMITED` 池自带 `limitParam.limitedCharId` 与起止时间，**零新资源文件**
- `games/arknights/engine.py`：`UpTargets` 加 `boost` / `boost_factor`；新增
  `member_weights` 让「5 倍」能被精确断言（不靠抽样）；`candidates` 支持按范围收窄
  限定渠道，且**只作用于 6★**（与 `boost_of` 同一条边界）
- `main.py`：`initialize` 构建 `LimitedIndex`；`_up_targets` / `_scope` 为限定池算范围；
  `/卡池查询` 多加一行「往期 5 倍 …」
- `views.py`：`boost_text` 与 `up_text` **分开传**，任一条缺失不影响另一条显示
- 不做：契约、300 井（留在 issue 07）、选调（06）、联动（09）、出图（11）

### 外源核对：四份官方公告逐字一致（2026-11-15）

名单不是模型自洽推出来的。PRTS 收录的四期公告原文里都写了「（在6★剩余出率【30%】
中以5倍权值出率提升）」，与 `LimitedIndex.scope_for` 的输出逐字比对：

| 池 | 公告的 5 倍名单 | 模型输出 |
|---|---|---|
| 劫尽古今（2026-02 春节） | 余 / 黍 / 重岳 | 一致 |
| 承诺（2026-05 庆典） | 新约能天使 / 荒芜拉普兰德 / 维什戴尔 | 一致 |
| 车辙与风的归所（2026-08 夏季） | 斩业星熊 / 佩佩 / 纯烬艾雅法拉 | 一致 |
| 将雪投火（2026-11 庆典） | 凛御银灰 / 新约能天使 / 荒芜拉普兰德 | 一致 |

公告还给了 5 倍的精确定义：「达到**其他单个 6 星干员**（除当期 UP 外）获得概率的
5 倍」。这确认了基数是剩余 30% 里的每一个非 UP 6★（含其他同系列限定），
不是只对标准干员加权——`member_weights` 里 `rest` 一视同仁给 1 倍正是对的。

### 三个容易写错的点

1. **系列必须按 UTC+8 判断**。`2026-11-01 07:00` 在 UTC 下是 `10-31 23:00`，按机器时区
   取月份会把整个池归到 10 月（不属于任何一档）。
2. **「最近三名」要在「已解限」之后取**，不是先取三名再排除。先取三名会把凛御银灰算进去，
   再排除就只剩两名，与官方公告对不上。
3. **当期 UP 要并回可登场集合**。它自己也在 11 个月解限期内，不并回去连当期限定都抽不到。

### 降级取舍

系列判不出来时返回「全体限定可登场、无人加权」：**多放几个人只是手感偏差，筛错会直接
少一档人**。范围把 6★ 筛空时退回不筛，与 R-14 降级链同一个取舍。

### 一个手算错误（记下来免得复查时再绕）

实测 5 倍三人占剩余 30% 份额的 24.3%，一度以为比理论 12% 高一倍。查过权重精确无误，
是我把标准寻访 6★ 当成 100 人算的——实际只有 46 人（其余 55 人是中坚专属）。
理论值应为 15/69 ≈ 21.7%，24.3% 在抽样噪声内。**核对占比前先数候选人数。**

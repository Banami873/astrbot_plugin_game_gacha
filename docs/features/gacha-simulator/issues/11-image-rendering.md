## Goal

`/单抽` 出一张 1024×576 的结果图、`/十连` 出一排 10 张互相压叠的竖卡；画面元素全部使用
游戏素材贴图，只有暗角、渐变、光晕、亮条由代码生成；渲染失败不影响已入账的结果。

## Scope

- `games/arknights/render/layout.py`：元素表（画布、卡片、立绘、星级条、职业图标、单抽各元素）
- `games/arknights/render/assets.py`：按元素表装载 `resources/ui/` 贴图与字体
- `games/arknights/render/draw.py`：合成单抽与十连
- `games/arknights/render/portraits.py`：半身像（十连）与精一立绘（单抽）的下载、验图、缓存；
  初始化起后台任务全量预热，限速 ≤1 次/秒
- `resources/ui/`、`resources/fonts/`：游戏 UI 贴图与字体随包
- 干员字典补 `name_en` / `profession` / `camp`（渲染的文字与图标来源，见 SPEC 数据文件表）
- `main.py`：抽卡事务之后出图；`enable_image=false` 或渲染异常时降级文字（R-15）
- 不做：动效、GIF、视频；不做像素级对齐（无游戏截图基准）

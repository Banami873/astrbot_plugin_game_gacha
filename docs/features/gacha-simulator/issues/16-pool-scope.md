# 16 — 选池作用域：不带词抽限定，类别不许退化

**目标**：两个游戏的抽卡指令统一成同一条规则——**不带词抽当期限定；第一个词写类别就在
那一类里找；那一类没开就报错**，绝不悄悄改抽常驻。

## 为什么

之前两边都是「能不猜就不猜，实在不行抽最新的」：

- 星铁不带词时在**全部角色池**里挑，有一张 `featured` 就抽它；
- 方舟不带词时「有限定抽限定，没有就抽最晚结束的池」。

第二种在限定池空窗期会把 `/十连` 变成抽常驻，玩家看不出区别，还会以为限定开了——数据上
完全合法，体验上是错的。这一轮把「抽哪个池」从「尽量给出一个结果」改成「玩家说了什么就
抽什么，说不清就问」。

## 规则

**星铁**（`games/hsr/pools.py::choose_pool`）

| 输入 | 抽谁 |
|---|---|
| `/星铁十连` | 当期限定（`featured` 那个角色池） |
| `/星铁十连 限定` | 同上；限定没开 → `no_scope` 报错 |
| `/星铁十连 复刻` / `复刻 火花` | 非 `featured` 的角色池（本期 3 张）；多张列候选 |
| `/星铁十连 角色` | 全部角色池（限定 + 复刻） |
| `/星铁十连 光锥` / `光锥 流光定影` | 全部光锥池（活动 + 联动）；多张时唯一 `featured` 优先 |
| `/星铁十连 联动` / `联动 Saber` | 联动角色池 |
| `/星铁十连 联动光锥` | 光锥联动池 |
| `/星铁十连 常驻` / `群星` | 群星跃迁 |
| `/星铁十连 愚戏众星` | 不带类别时在**全部**在开池里按池名 / 合集名 / UP 名找 |

**方舟**（`games/arknights/pools.py::choose_pool`）

| 输入 | 抽谁 |
|---|---|
| `/十连` | 最新的**限定**池；没开 → `no_limited` 报错并列出在开的池 |
| `/十连 限定` | 限定 ∪ 联动；同时开着时**优先限定**，都没开 → `no_category` |
| `/十连 联动` | 联动；没开 → 报错 |
| `/十连 常驻` / `限时` / `中坚` | 对应类别 |
| `/十连 庆典` | 不带类别时在全部在开池里按池名找（前缀优先，再降级为包含） |

**共同点**：关键词必须**完全相等**且在最前面；类别之后的都算名字；名字只在该类别里找，
不会因为「全局能对上」就跨类别抽。作用域为空一律报错，文案里说明「不会自动改抽常驻」并
列出现在开着什么。

## 验收

- 星铁：`/星铁十连` 抽到当期新角色；`/星铁十连 复刻` 列出 3 张复刻；`复刻 阿哈`（阿哈是
  限定 UP）报 `unknown` 而不是抽到限定；光锥池只在这 4 张里找。
- 方舟：限定没开时 `/十连`、`/十连 限定`、`/十连 联动` 全部报错且**不扣抽数**；`/十连 限定`
  在只开联动时抽联动，两者都开时抽限定。
- 文案：每条失败都给出「现在开着什么」和一条能直接照抄的指令，不出现内部 id。
- 全量 pytest 通过（704 条）；方舟原有断言除「指令字符串补上类别」外一条未改。
